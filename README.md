# 💱 Currency Converter

A simple currency converter built with **React.js** and **ExchangeRate-API**.

## Features

- 💰 Convert currency
- 🌎 Select From and To currency
- 🔄 Real-time exchange rates
- 🔢 Result up to 2 decimal places

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- ExchangeRate-API
